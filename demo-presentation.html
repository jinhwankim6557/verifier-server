06 — DIFFERENCE

일반 AI 채팅과 뭐가 다른가?

일반 AI 채팅 Claude Code
코드 전달 내가 복사해서 붙여넣기 AI가 프로젝트에서 직접 읽음
결과물 채팅창에서 복사 → 파일 저장 프로젝트 안에 파일 직접 생성
이해 범위 붙여넣은 코드 조각만 엔티티, API, 설정, 구조 전체
실행 불가 빌드, 테스트, git 등 명령 실행
컨텍스트 유지 대화 기록만 CLAUDE.md + 프로젝트 파일 + 대화

핵심: 코드를 AI에게 가져가는 게 아니라, AI를 코드에 데려온다

07 — PROMPT TIPS

요청할 때 이렇게 하면 잘 나온다

  • 1
    참조할 파일/코드를 직접 지목한다
    ✓ "admin-oid4vp-mockup.html 스타일 참고해서"   ✓ "entity/ 하위 엔티티 읽어봐"
    → AI가 스스로도 찾지만, 지목하면 정확도와 속도가 올라감
  • 2
    구체적으로 요청한다
    ✗ "대시보드 만들어줘"    ✓ "통계 카드 4개, 테이블 10건, 다크 사이드바로 만들어줘"
  • 3
    한 번에 완벽할 필요 없다 — 대화로 발전시킨다
    첫 결과 70~80% → 수정 요청 2~3회 → 90% 이상
    피드백 루프가 핵심이다

⚠️ 주의사항
파일 수정 시 권한 확인이 뜸 (안전장치)
결과물은 반드시 리뷰 — AI는 도구이지 대체재가 아님
10 — MODELS

모델 비교

Haiku
빠르고 가벼운 모델
✓ 가장 빠른 응답 속도
✓ 간단한 코드 수정, 질문
✓ 비용 효율 최고
△ 복잡한 분석·추론은 한계
Sonnet
균형잡힌 메인 모델 — 추천
✓ 빠른 속도 + 높은 품질
✓ 코드 생성, 분석, 리팩토링
✓ 일상 개발의 90% 커버
✓ 속도와 품질의 최적 밸런스
Opus
최고 성능 모델
✓ 가장 깊은 추론 능력
✓ 복잡한 아키텍처 설계
✓ 대규모 멀티파일 리팩토링
△ 응답 속도 느림
요금제 가격 토큰
Pro $20 /월 일반 사용량
Max 5x $100 /월 Pro 대비 5배
Max 20x $200 /월 Pro 대비 20배

/model 모델 변경  ·  /usage 사용량 확인
